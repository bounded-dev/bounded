# 2026-006: A tool use is a list of precise effects

**Status:** accepted. Supersedes the tool-use shape in ADR 2026-005. Amended by ADR 2026-019: a delegate effect also carries `isolated?` and `finishUnreported?`, and a tool result carries `delegatedAgentRuns`. Amended by [ADR 2026-020](2026-020-shell-command-reading.md): an execute effect carries a required reading built by the host adapter (ADR 2026-020, corrected), bounded's reading of its command (programs, file effects, unresolved parts); results carry one too. Amended by [ADR 2026-025](2026-025-agent-run-finish.md): a `delegatedAgentRuns` entry may also give `agentRunId`, `finishReportedLater: true` and `resolvedAgent`, typed on the wire by `DelegatedAgentRunJSON`.

## Decision

A tool use is `{ kind: "tool-use", role, tool, effects }`. `tool` is the
host-neutral tool kind (read, search, edit, write, shell, web, subagent,
other), kept for allowlists of tools. `effects` is a non-empty list of what
the call actually does, each one of seven kinds:

| Effect | Fields | Meaning |
| --- | --- | --- |
| `read` | `path` | reads a file's contents |
| `list` | `root`, `filter` (a file-name pattern, or null) | lists names only, no contents |
| `write` | `path`, `change`: create, modify or delete | changes a file |
| `execute` | `command`, `cwd` (the project directory it runs in, or null) | runs a shell command, and nothing else |
| `fetch` | `url` | reaches the network |
| `delegate` | `agent`, `isolated?`, `finishUnreported?` (ADR 2026-019) | hands work to another agent |
| `invoke` | `name` | calls a tool whose effects the host cannot describe |

Paths, including an execute's `cwd`, are `ProjectPath`s, checked and
normalised; an adapter refuses a command whose directory is outside the
project rather than leaving `cwd` out. A command must not be
blank or hold NUL or control characters other than tab and line breaks; a
URL is absolute with a scheme and holds no spaces or control characters; an
agent's or tool's name is not blank and holds no control characters. Each
kind has exactly its own fields: a field of another kind, or a missing one,
is refused, so nonsense such as a read with a command cannot be built.

How a host adapter maps its tools: a glob is a `list`; a content search is a
`list` and a `read` over the same root; a multi-edit is several `modify`
writes; a rename is a `delete` and a `create`; a shell command is an
`execute`; an unknown tool, a tool from another server, a skill or a web
search without a URL is an `invoke`. Deleting or renaming a directory is one
`write` effect per file it contains plus one for the directory itself (ADR
2026-009).

## Why

Gates judge what happens, not what a host calls its tools. A coarse action
with independent paths, command and search fields could not say which path a
command writes or whether a search reads contents; a list of effects can,
and a guard judges one effect at a time (ADR 2026-007).

## Consequences

The slice 2 tool-use tests replaced by this model are recorded in
`superseded-tests.json` with their successors.
